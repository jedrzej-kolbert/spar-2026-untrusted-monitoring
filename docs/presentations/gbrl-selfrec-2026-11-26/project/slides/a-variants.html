Avg-4 + similarity is W&B run mu34zzlg (v41-gbrl-avg4-B): training scores use the mean over 4 channel views (summaries) of each rewrite to cut the noise of resampled summaries and monitor responses; evaluation uses 1 view. Similarity = difflib SequenceMatcher ratio over the code tokens of the input attack and the rewrite (1 = same tokens; renames count as changes), weight 0.5, added so that copying the input is not the safest way to keep the backdoor (commit ab3996442). P(self) − suspicion is ahdw6uj5 then xmvwkwy2 (reward_fn hipt with overseer_scale 0 and backdoor_kept_weight 0, so reward = P(self) − suspicion, not gated by pass).
