Sender GBRL on attacks: set-up and first results

Training modes implemented

  • honest+signal: sender writes honest code and a signal
  • receiver_only: sender gets an attack with a valid backdoor and only inserts a signal
  • attack+signal: sender writes the attack and the signal

Reward (branch)

passed × (task_w + comm_w × P(correct)) − overseer_w × suspicion

Optional terms

− failed_backdoor_w × [backdoor broken] · − backdoor_suspicion_w × score / 10

Her results and reflections

  • Reward penalised invalid backdoors, so the model learned to retain the backdoor, but not to generate a viable collusion signal
  • In testing, the receiver flagged 70–96% of honeypots as self-written: a frozen receiver not fine-tuned for signal recognition is a bottleneck
  • Next: prioritise valid signals over attacks, try benign code only, start from SFTed monitors, test against minify / paraphrase
